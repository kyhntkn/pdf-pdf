# PDF Studio (Python)

Çevrimdışı PDF dönüştürücü ve düzenleyici.

## Çalıştırma
    pip install -r requirements.txt
    python app/main.py

## Exe derleme
GitHub'a yükleyin; Actions > Build exe. Çıktı: `PDF-Studio.zip` (içinde `PDF-Studio/PDF-Studio.exe`).
Zip'i bir klasöre çıkarıp exe'yi çalıştırın.
